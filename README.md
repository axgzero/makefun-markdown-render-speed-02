A fast, dependency-free Markdown renderer that returns byte-for-byte the HTML marked 18.1.3 produces with default options (GFM, CommonMark 0.31.2 + GFM 0.29 extensions), written from scratch as a single ES module. `parse(markdown)` handles headings, lists (tight/loose, task items), tables, fenced and indented code, block quotes with lazy continuation, link reference definitions, inline HTML, emphasis/strong/strikethrough, links, images, autolinks and extended autolinks — then renders it faster than marked itself.

## Run it

```sh
node main.ts
```
